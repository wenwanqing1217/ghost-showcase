# Ghost / Alpha-ID 一晚上出成果计划

## 核心策略

不做新功能开发，**只做三件事**：
1. **连接已有的死代码**（AgentLoop 路由已有，TwinBrain 注入已有，A2A 路由已有）
2. **让 Docker 跑起来**（补齐缺失的 Dockerfile）
3. **写一个端到端验证脚本**（证明整条链跑通）

## 具体任务

### 任务 1：修补 3 个缺失的 Dockerfile
- **Alpha-ID** (`alphaid/projects/Dockerfile`) — 参考 nebula Dockerfile 模式
- **Feishu-Bot** (`ghost-main/feishu-bot/Dockerfile`) — 让飞书 bot 可容器化
- **Nebula** (`nebula/Dockerfile`) — docker-compose 已引用但目录缺失

### 任务 2：修补 net_agent 竞态条件
- `ghost-main/net_agent_server/task_queue/task_manager.py:31` — SELECT-then-UPDATE 改为原子操作

### 任务 3：写端到端验证脚本
- `scripts/e2e_test.py` — 自动执行：
  1. `quick-register` 获取 JWT
  2. `POST /api/v1/agent/chat` 调用 AgentLoop
  3. 验证响应有 reply 内容
  4. 检查双链记忆写入
  5. 检查审计日志记录

### 任务 4：修补 Ghost.html 面板数据连接
- 9 个面板中仅 2 个有 fetch — 补齐剩余面板的数据获取

## 验收标准

执行 `docker compose up -d` → 7 个服务全部 healthy → 运行 `scripts/e2e_test.py` → 输出绿色 PASS

不做的事：不写新功能、不改架构、不做前端重构、不碰模拟盘/3D 宇宙等远期愿景。
