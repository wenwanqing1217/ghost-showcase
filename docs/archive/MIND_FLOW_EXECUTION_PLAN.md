## 三、飞书 vs 微信 对比

### 3.1 飞书（推荐）

| 优势 | 劣势 |
|------|------|
| 机器人开发简单，文档全 | 用户量少（你自己用没问题） |

| 开放平台稳定 | 生态不如微信 |
| 永久免费额度 | 不适合C端推广 |

**适合场景**：个人助理、工具类、内部使用

### 3.2 微信服务号

| 优势 | 劣势 |
|------|------|
| 用户量大 | 需要企业认证（300元/年） |

**适合场景**：C端产品、需要支付、需要传播

### 3.3 结论

**第一阶段（2周）**：用**飞书**，快速验证产品逻辑
**第二阶段（月活>100）**：如果飞书够用，继续用；如果需要推广，加微信服务号

> MindFlow = 全栈 AI 工作流平台
> 
> 即：把 AI 能力编排成工作流，让用户用自然语言驱动自动化任务

### 4.3 数字身份基础建设体现在哪？

| 模块 | 当前状态 | 落地路径 |
|------|----------|----------|
| **DID 身份** | Alpha-ID 已有骨架 | 2周内集成到 MindFlow Map |

## 五、完整工作流示例（从输入到产出）

### 5.1 场景：地图导航

```
你在飞书说："明天上午9点去中关村，帮我规划路线"
    ↓
MindFlow 工作流：
1. [意图识别] AI 理解：导航 + 时间 + 地点
2. [身份查询] 从 AID 获取你的 DID 和历史偏好
3. [地点搜索] 调用百度地图 API 搜索"中关村"
4. [路线规划] 调用百度地图 API 规划路线
5. [时间优化] 结合明天9点的路况，推荐出发时间
6. [记忆存储] 记录这次行程到 AID 记忆层
7. [结果返回] 飞书卡片展示：路线图 + 预计时间 + 打车费用
```

### 5.2 场景：短剧自动化

```
你在飞书说："帮我发一个短剧剧本，标题是《霸道总裁爱上我》"
    ↓
MindFlow 工作流：
1. [AI 剧本生成] 调用豆包 API 生成短剧剧本
2. [分镜脚本] AI 自动生成分镜和台词
3. [你的审核] 飞书发送剧本给你，你回复"通过"或"修改"
4. [自动发布] Computer Use 自动登录抖音短剧平台，发布剧本
5. [收益追踪] 每天自动读取平台数据，汇总给你
```

### 5.3 场景：电商运营

```
你在飞书说："优化我的 Shopify 店铺，提高转化率"
    ↓
MindFlow 工作流：
1. [数据读取] 调用 Shopify API 读取当前数据
2. [AI 分析] 豆包 API 分析哪些产品需要优化
3. [内容生成] AI 生成新的商品文案和图片描述
4. [广告优化] 自动调整广告预算和关键词
5. [你的确认] 飞书发送优化方案，你回复"执行"
6. [自动执行] 调用 Shopify API 更新产品和广告
7. [效果追踪] 每天汇总销售数据给你
```

## 六、两周执行计划

### Phase 1：基础架构（Day 1-3）

**Day 1：飞书机器人 + 后端框架**
- 创建飞书机器人应用
- 搭建 Python FastAPI 后端
- 实现基础对话："你好"、"能做什么"

**Day 2：MindFlow 工作流引擎**
- 实现意图识别模块
- 实现工具调用框架
- 实现上下文记忆

**Day 3：AID 身份集成**
- 集成 Alpha-ID DID
- 实现用户身份查询
- 实现记忆读写

### Phase 2：地图助理（Day 4-7）

**Day 4-5：百度地图 API 集成**
- 地点搜索 API
- 路线规划 API
- 地理编码/逆地理编码

**Day 6-7：智能推荐**
- 结合时间推荐出发时间
- 常去地点记忆
- 飞书卡片展示

**里程碑**：你在飞书说"怎么去中关村"，能看到路线图

### Phase 3：短剧自动化（Day 8-12）

**Day 8-9：AI 剧本生成**
- 调用豆包 API 生成剧本
- 剧本模板化（甜宠/悬疑/都市）
- 质量评估

**Day 10-11：Computer Use 自动发布**
- Playwright 自动化登录抖音短剧平台
- 自动填写表单、上传内容
- 异常处理

**Day 12：收益追踪**
- 自动读取平台数据
- 飞书日报推送

**里程碑**：AI 生成剧本，你审核，自动发布到抖音短剧平台

### Phase 4：电商运营（Day 13-14）

**Day 13：Shopify 集成**
- 读取产品数据
- AI 生成文案
- 自动更新

**Day 14：广告优化**
- 广告数据读取
- AI 优化建议
- 自动执行

**里程碑**：Shopify 店铺自动运营
