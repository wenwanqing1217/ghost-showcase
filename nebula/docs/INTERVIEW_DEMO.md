## 演示流程（5分钟）

### 1. 开场白（30秒）

> "MindFlow Map 是一个 AI 统一工作流引擎。核心解决的是：员工今天用百度地图查路线、明天用飞书跟客户沟通、后天用抖音发短剧、大后天用 Shopify 管店铺——信息散在四个平台，记忆不共享，操作不统一。MindFlow 把这些平台统一到一个工作台里，用一个 AI 大脑处理所有请求。"

### 2. 演示 Workspace 工作台（1分钟）

- 打开 `http://localhost:2002/workspace`
- 展示左侧导航：工作台、AI 对话、地图助理、短剧管理、电商运营、书签收藏
- 展示快速启动区：百度地图、飞书、Shopify、抖音、AI 对话、书签
- 展示集成状态卡片

**话术**：这是员工统一入口，所有平台都在这里，不用在浏览器开十几个标签页。

### 3. 演示地图查询（1分钟）

- 切换到「地图助理」
- 输入「中关村」，点击查询
- 展示真实返回的地点结果

**话术**：这里接的是百度地图 Agent Plan 真实 API，不是模拟数据。支持语义化地点检索、路线规划、天气查询。

### 4. 演示路线规划（1分钟）

- 在路线规划区，起点输入「中关村」，终点输入「故宫」
- 点击「规划路线」
- 展示距离和预计时间

**话术**：这是 AI 原生路线规划，不是简单的地图跳转。MindFlow 理解自然语言，自动规划最优路线。

### 5. 演示 AI 对话（1分钟）

- 切换到「AI 对话」
- 输入「怎么去天安门」
- 展示 AI 回复（已识别为导航意图，返回路线规划结果）

**话术**：这是统一工作流引擎。不管是 Workspace、飞书还是微信发来的消息，都经过同一套意图识别和工具编排。现在默认用 DeepSeek/豆包做 NLU，识别不到时自动回退到规则引擎，兼顾 AI 能力和稳定性。

### 6. 后台 API 展示（30秒）

- 打开 `http://localhost:2002/docs`
- 展示自动生成的 API 文档
- 可以现场调用一个 `/api/v1/map/search` 接口

**话术**：所有能力都通过 RESTful API 暴露，方便二次开发和集成。

### 7. 飞书入口说明（30秒）

- 展示飞书长连接已启动（看终端日志或说明）
- 说明手机端发消息给飞书机器人，会触发同一套工作流

**话术**：员工在飞书里直接发消息就能用，比如发「帮我查一下明天去故宫的路线」，MindFlow 自动处理并回复。

### 8. 扩展模块说明（1分钟）

- 抖音短剧：Playwright 自动化框架已搭好，状态机管理登录/发布流程，支持 cookie 注入；未配置账号时返回友好提示
- Shopify：Admin API 客户端已对接，可查询商品、管理订单；未配置 token 时返回模拟结果
- 微信公众号：Webhook 适配器已实现，支持签名验证、Access Token 缓存、文本消息自动回复；配置校验可通过 `/health/config` 查看
- 多线程优化：工作流引擎支持并发执行多个工具请求，Alpha-ID 客户端支持 tenacity 重试 + asyncio.gather 并发 + TTL 缓存

**话术**：这些模块现在都是演示接口，但架构已经打通。生产环境只需要填真实的 API Key 和登录态，就能快速上线。

## 常见问题准备

**Q: 百度地图 API 要钱吗？**
A: 百度地图 Agent Plan 每天 30 万次免费调用，足够中小团队用。超出后也很便宜。

**Q: 飞书长连接和 Webhook 有什么区别？**
A: 长连接是客户端主动连服务器，不需要公网 IP 和域名。Webhook 需要服务器暴露在公网，接收飞书推送。MindFlow 用长连接，部署更简单。

**Q: 抖音短剧怎么实现自动发布？**
A: 现在用 Playwright 模拟人工操作，登录后自动填写表单发布。后续可以接入抖音官方 API 实现更稳定的自动发布。

**Q: 数据安全吗？**
A: 所有 API Key 都存在本地 .env 文件，不会上传。Alpha-ID 用户上下文是可选的，不配置也能正常运行。

**Q: 和竞品比有什么优势？**
A: 大多数工具只解决单一平台问题，比如只做地图或只做电商。MindFlow 的核心是统一工作流引擎，一套逻辑服务多端，记忆共享，操作统一。

**Q: 这个项目最大的技术难点是什么？**
A: 意图识别的准确性和多平台状态的统一管理。比如用户在飞书说「帮我查一下路线」，MindFlow 要知道调用百度地图，还要记住用户上次的位置，这些都需要 AI 原生架构支持。

**Q: 为什么不用大模型做意图识别？**
A: 现在默认接入 DeepSeek/豆包做 NLU，识别失败时自动回退规则引擎，保证稳定性。这样既有 AI 能力，又有兜底保障。

**Q: 支持哪些平台？**
A: 目前接入飞书、微信公众号、百度地图，框架支持抖音和 Shopify。配置状态可通过 `/health/config` 查看。架构是插件化的，新增平台只需要写一个工具适配器。

**Q: 部署复杂吗？**
A: 很简单。`pip install -e .` 安装依赖，配置 .env，`uvicorn` 启动。Windows 有 start.bat 一键启动，Linux/Mac 有 start.sh。
