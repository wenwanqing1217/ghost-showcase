# CodeTime Machine

> AI 代码考古 + 时间旅行式代码浏览，像看历史一样看代码演变。

## 核心创新

 legacy 代码是一座矿山。CodeTime Machine 用 AI 读懂遗留系统、映射依赖、自动现代化，并提供**时间旅行式的代码浏览体验**——你可以像看历史纪录片一样，回溯代码的每一次重要演变。

## 关键特性

- **AI 代码考古**：自动分析遗留代码，生成架构图和依赖地图
- **时间旅行浏览器**：可视化代码历史，按时间线浏览重要变更
- **智能现代化**：AI 建议代码现代化路径，自动生成迁移方案
- **依赖可视化**：交互式展示模块间的依赖关系和变更传播
- **知识提取**：从代码历史中提取业务逻辑和设计决策

## 成长路径

```
工具层（代码考古）→ 服务层（现代化咨询）→ 平台层（企业代码资产平台）
```
