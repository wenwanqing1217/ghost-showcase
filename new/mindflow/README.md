# MindFlow

> 个人 AI 生活操作系统 — Agent 编排 × 语音交互 × 知识图谱

## 一句话定位

不是又一个 AI 聊天机器人，而是一个**能理解你、帮你做决策、替你执行任务的 AI 生活操作系统**。

## 与 AID 的关系

| 项目 | 解决什么 | 核心能力 | 关系 |
|------|----------|----------|------|
| **AID** | "你是谁" | DID + 记忆 + Ghost Layer | 数字身份的锚点 |
| **MindFlow** | "帮你做什么" | Agent 编排 + 任务执行 | 在这个锚点上的手脚 |

MindFlow 是 **Agent 任务执行层**，身份问题交给 AID。MindFlow 可以使用 AID 的 DID 和记忆层，也可以独立运行。

## 三大核心模块

### 1. Agent 编排工作台（核心）

**做什么**：用户通过可视化界面编排多个 AI Agent，让它们协同完成任务。

**场景示例**：
- "帮我找适合送室友的盲盒" → 搜索 Agent + 推荐 Agent + 比价 Agent 协作
- "安排周末行程" → 日程 Agent + 配送 Agent + 社交 Agent 协作
- "完成作业 + 买教材 + 约同学讨论" → 学习 Agent + 购物 Agent + 社交 Agent 协作

**关键特性**：
- 可视化工作流编辑器（拖拽编排）
- 多 Agent 协作（搜索、写作、分析、代码等）
- Agent 市场（发现、分享、购买工作流）
- 运行时沙箱（安全执行，权限和配额管理）
- API 集成（连接外部工具和真实世界）

**成长路径**：工具 → 市场（Agent 工作流分享）→ 生态

### 2. 语音优先交互

**做什么**：用户用自然语言语音与系统交互，替代传统点击操作。

**场景示例**：
- "帮我发个盲盒" → 语音引导填写信息 → 自动发布
- "今天有什么订单要送？" → 语音播报配送任务
- "推荐点好玩的" → 语音推荐盲盒 + 社区动态

**技术核心**：语音识别 + 语义理解 + 场景化响应 + 语音合成

**成长路径**：工具 → 平台（语音生态）→ 社区

### 3. 动态知识图谱

**做什么**：用户的所有行为、偏好、关系自动构建成一张会演化的知识网络。

**场景示例**：
- "我记得室友喜欢动漫，有没有相关的盲盒？" → 从知识图谱检索社交关系 + 偏好
- "我上个月买过什么？" → 时间旅行式知识查询
- "我最近在研究 AI，有没有相关的社区讨论？" → 知识关联推荐

**技术核心**：向量数据库 + 知识图谱引擎 + 自动关联算法

**成长路径**：个人 → 团队 → 企业
